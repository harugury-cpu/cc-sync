# 사용자 프로필

## 직장 및 역할
- 회사: Spigen
- 팀: 패키지팀 (패키지 설계 및 제품 보호, 내장재 선정 담당)
- 역할: 패키지 시안 작업, 샘플 확인, 이미지 요청, 셀링포인트 정리, 업무 자동화 리딩
- 조직: 파트장(section chief)과 함께 일함, 파트회의 진행

## 주요 업무 도구
- Monday.com — 업무 트래킹 (Monday API 자동화 진행 중)
- Google Apps Script (GAS) — Monday 자동화 스크립트 작성
- Google Chat (gchat) — 팀 커뮤니케이션, bot 자동화 연동
- Google Slides — 발표자료 제작
- Adobe Illustrator — 패키지 전개도(box-engine), 디자인 시안
- drawio — 다이어그램 작성 (Mermaid 유료라서 대체 사용)
- Obsidian — 개인 노트 (vault 3개: 메인, obsidian-mind, 개인노트)
- iCloud — 파일 동기화
- GitHub — 코드 관리 (harugury-cpu 계정)

## 기술 스택 / 자동화
- Claude Code + cokacdir — 로컬 자동화 구축 중 (메인 AI 도구)
- Codex — 구독제로 사용 중 (Claude API는 과금 문제로 미사용)
- yt-dlp + notebooklm-py — YouTube → NotebookLM → 인포그래픽 파이프라인
- Python, Bash 스크립트 직접 작성
