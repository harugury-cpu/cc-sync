## 파닥몬 Monday 업무 기록 규칙

- 사용자가 파닥몬에게 `나 지금 뭐 했어` 또는 `나 오늘 뭐했어`라고 말하면 Monday 보드 `한원진_기타업무`에 오늘 업무 아이템을 생성한다.
- 대상 보드: `https://spigen.monday.com/boards/18416490977`
- 생성 위치: `오늘` 그룹 (`group_mm41gbke`)
- 필수 입력값: 업무명, 작업구분, 소요시간, 생성일
- 작업구분은 기존 라벨 `기타`, `R&D`, `제작` 중 하나를 사용한다.
- 사용자가 작업구분이나 소요시간을 말하지 않으면 추측하지 말고 먼저 물어본다.
- 생성일은 별도 언급이 없으면 현재 날짜를 사용한다.
