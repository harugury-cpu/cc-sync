# 업무정량화 구현 작업 사양서

## 1. 목적

- 완료된 업무를 설문 응답과 시트 룰을 통해 정량 시간으로 환산한다.
- 개인 평가 시간과 item/팀 총 업무량을 분리한다.
- 재설문과 RC/기타/지원파트 시간을 중복 없이 반영한다.

## 2. 시스템 구성

```text
Monday 완료 보드
→ Apps Script Webhook
→ Google Sheet
→ 설문 HTML
→ 계산 엔진
→ 계산결과
→ AI HTML 리포트
```

## 3. 책임 분리

### Monday

- 완료 이벤트 발생
- 원래 업무 item ID, SKU, 라인업코드, 담당자, 완료일 전달
- 계산 기준으로 사용하지 않음

### Google Sheet

- 완료 이벤트 이력 저장
- 업무로그 현재상태 저장
- 설문응답 원본 저장
- 룰/계수 관리
- 계산결과 저장

### 설문 HTML

- 작업구분 선택
- 티셔츠/횟수 응답
- RC/기타 입력
- 재설문 시 기존 응답 기반 수정

### Apps Script

- Monday webhook 수신
- 시트 입출력
- 설문 배치 생성
- 응답 저장
- 계산 실행
- 관리자 재설문 처리

## 4. 모듈 목록

1. Monday 완료 이벤트 수집
2. 완료이벤트누적 저장
3. 업무로그 매칭
4. 설문 배치 생성
5. 설문 HTML 렌더링
6. 설문 응답 저장
7. 계산 엔진
8. 관리자 재설문
9. 파트장/지원파트 시간 처리
10. 리포트 입력 데이터 생성

## 5. 핵심 데이터 흐름

```text
완료 처리
→ 완료이벤트누적 append
→ 원래 업무 item ID + 담당자로 업무로그 조회
→ 업무로그 신규/갱신
→ 라인업코드 기준 설문 배치
→ 설문 응답 저장
→ 업무로그 최신응답 갱신
→ 계산결과 재생성
```

## 6. 시트 탭 책임

- 완료이벤트누적: 완료건 원본 이력
- 업무로그: 담당자별 업무 현재상태
- 설문응답원본: 설문 제출 이력
- 계산결과: 항목별 계산 근거
- 설문룰편집: 사람이 관리하는 질문/기준시간
- 설문질문룰: 시스템 읽기용 정규화 룰
- 티셔츠계수룰: 티셔츠 사이즈별 계수
- 기타작업룰: RC/기타 자동가산 규칙
- 담당자매핑: 발송 대상/채널

9. 지원파트 시간 처리 구현
10. 테스트 케이스 검증

## 9. 완료 기준

- 완료 이벤트가 중복 저장되지 않는다.
- 같은 원래 업무 item + 담당자는 하나의 업무로그로 유지된다.
- 재설문은 기존 업무로그 최신값을 갱신한다.
- 라인업코드가 있으면 설문은 묶이고 결과는 개별 item에 반영된다.
- 계산결과는 룰 탭 기준으로 재생성된다.
- 지원파트 시간은 별도 로그로 저장되고 item 기준 합산된다.
