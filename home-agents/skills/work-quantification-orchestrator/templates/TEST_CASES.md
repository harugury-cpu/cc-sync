# 업무정량화 테스트 케이스

## CASE 01. 라인업코드 묶음 설문

조건:
- 같은 라인업코드
- 같은 담당자
- 10분 안에 완료건 여러 개 발생

기대 결과:
- 설문은 1회 발송
- 업무로그는 item별로 유지
- 응답 결과는 각 item 업무로그에 반영

## CASE 02. 라인업코드 없는 item

조건:
- 라인업코드 없음
- 원래 업무 item ID 있음

기대 결과:
- item별 설문 발송
- 같은 원래 업무 item + 담당자 기준으로 업무로그 생성/갱신

## CASE 03. 같은 업무의 RC 재완료

조건:
- 같은 원래 업무 item ID
- 같은 담당자
- 완료건 ID는 새로 생성

기대 결과:
- 완료이벤트누적에는 새 완료건 append
- 업무로그 새 행 생성 없음
- 기존 업무로그 최신응답/계산값 갱신

## CASE 04. 관리자 재설문

조건:
- 업무로그에서 관리자가 대상 선택
- 재설문 발송

기대 결과:
- 설문응답원본에는 새 응답 이력 append
- 업무로그는 기존 행 최신값 갱신
- 계산결과는 최신 응답 기준 재생성

## CASE 05. 티셔츠 기본값 초과

조건:
- 기본값 S
- 담당자가 L 선택

기대 결과:
- 기준시간 × L 계수로 계산
- 사이즈업 사유 필수 저장
- 관리자 확인 후보로 필터 가능

## CASE 06. RC 자동가산

조건:
- 설문에서 RC 선택

기대 결과:
- 기타작업룰에 따라 크로스체크 +1
- 인계 +1
- 계산결과에 자동가산 근거 저장

## CASE 07. 지원파트 시간 합산

조건:
- 지원자가 연결 item 선택
- 업무내용과 투입시간 입력

기대 결과:
- 지원자 개인 평가에 반영
- 원 담당자 개인 평가에는 섞이지 않음
- item 총 업무량에는 합산
