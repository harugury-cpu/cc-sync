# QA Gate

## 구현 전 확인

- [ ] PRD가 최신 흐름을 반영하는가
- [ ] Google Sheet 탭 책임이 확정되었는가
- [ ] 업무키와 설문배치키가 분리되어 있는가
- [ ] 원래 업무 item ID를 완료건에서 받을 수 있는가
- [ ] 라인업코드 없는 경우 처리 기준이 있는가
- [ ] 재설문은 새 업무가 아니라 기존 업무 갱신으로 정의되어 있는가

## 구현 후 확인

- [ ] 완료건 ID 중복 처리 방지가 작동하는가
- [ ] 완료이벤트누적과 업무로그가 섞이지 않는가
- [ ] 같은 원래 업무 item + 담당자가 하나의 업무로그로 유지되는가
- [ ] 라인업코드 묶음 설문 결과가 개별 item에 반영되는가
- [ ] 설문응답원본은 append-only로 남는가
- [ ] 업무로그는 최신 응답 기준으로 갱신되는가
- [ ] 계산결과는 재생성 가능하게 설계되었는가
- [ ] 티셔츠 기본값 초과 사유가 저장되는가
- [ ] RC 자동가산이 기타작업룰 기준으로 작동하는가
- [ ] 지원파트 시간이 개인 평가와 item 평가에 각각 올바르게 반영되는가

## 회귀 테스트

- [ ] 최초 완료
- [ ] 라인업 묶음 완료
- [ ] 라인업 없는 완료
- [ ] RC 재완료
- [ ] 관리자 재설문
- [ ] 미응답
- [ ] 기타/사유 입력
- [ ] 지원파트 시간 입력
